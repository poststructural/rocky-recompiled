# Controls

A controller works through SDL (Xbox, PlayStation, Switch and most others);
the keyboard works at the same time. Rocky's own controls screen (in its
Options menu) says what each button does in a fight.

## Controller

| Xbox button | Modern controller |
|---|---|
| A, B, X, Y | A, B, X, Y (Cross, Circle, Square, Triangle) |
| Black | Left bumper |
| White | Right bumper |
| Left / right trigger | Left / right trigger |
| Left / right stick, click | Left / right stick, click |
| D-pad | D-pad |
| Start | Start / Menu / Options |
| Back | Back / View / Share |

## Keyboard

| Xbox button | Key |
|---|---|
| Left stick | W A S D |
| Right stick | Numpad 8 4 5 6 |
| D-pad | Arrow keys |
| A | Space or K |
| B | L |
| X | J |
| Y | I |
| Black | E |
| White | R |
| Left trigger | Q |
| Right trigger | Shift |
| Left / right stick click | F / G |
| Start | Enter |
| Back | Backspace |

## Window and PC keys

| Key | |
|---|---|
| F1, or Back + Start | PC OPTIONS over the paused game |
| F10 | frame rate counter |
| F11, Alt+Enter | fullscreen / windowed |

## Launcher

Arrow keys or the D-pad choose, Enter / A selects, Esc / B goes back; the
mouse works too.
