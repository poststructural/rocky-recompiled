Rocky Recompiled 1.0.0: an unofficial native PC version of Rocky (original
Xbox, 2002), made by static recompilation. It contains none of the game's
data: you need your own copy of Rocky for the original Xbox (USA).

**Install:** unzip anywhere and start `Rocky.exe`. The launcher asks for your
disc image the first time (.iso, the .zip/.7z it came in, or the default.xbe
of an extracted copy) and installs the game files once.

**What's in it**

- The game runs at a steady 60 fps: movies, menus, the Movie Mode career
  (fights, saving) and exhibition matches have been played through; other
  modes are expected to work but have had less testing.
- Any resolution, windowed or fullscreen, render scale up to 8x, anisotropic
  filtering.
- Widescreen and ultrawide fights through the game's own 16:9 mode (more of
  the ring at the sides); menus and movies kept at 4:3.
- PC OPTIONS in game (F1, or Back + Start), and a launcher with settings,
  mods, game files and updates.
- Controllers through SDL (Xbox, PlayStation, Switch and others) and the
  keyboard.
- Mods: files in `mods/<name>/` replace the game's own.
- Updates from this page, from the launcher (saves, settings and mods kept).
- Portable mode (`portable.txt` beside the exe).

**Needs** Windows 10 or 11 (64-bit) and a GPU with Vulkan 1.3 drivers.
